# TIBCO Messaging Quickstarts

Hands-on, copy-paste-friendly quickstarts for the TIBCO messaging products.

## Read the Docs

The quickstarts are best read as a rendered site:

### **[tibcosoftware.github.io/msg-quickstart](https://tibcosoftware.github.io/msg-quickstart/)**

Local install and Docker walkthroughs, with tabs for Linux, Windows, and macOS.

## What's Inside

| Quickstart | Highlights |
| --- | --- |
| **TIBCO FTL®** | Low-latency, high-throughput messaging &mdash; local & Docker walkthroughs, client API reference. |
| More on the way | Additional TIBCO messaging quickstarts are in development. Watch this space. |

## Build the Site Locally

```bash
cd quickstart
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000).
