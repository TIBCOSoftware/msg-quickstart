# TIBCO FTL® Quickstart
***TIBCO FTL*** is a high-performance, low-latency messaging solution engineered for both enterprise and cloud-ready environments, and with the ability to handle massive message volumes with built-in high reliability and availability.

This tutorial offers a simple, hands-on introduction to TIBCO FTL using the preconfigured setup and sample programs included with the standard package. First, start an FTL server and explore key messaging patterns through practical, ready-to-run examples. This guide will provide two options to get started with TIBCO FTL:
- Get started with a standalone FTL server using a [Docker container](quick-start/qs-docker.mdx).
- Get started with a standalone FTL server using a [local installation](quick-start/qs-local.mdx).

You can also explore the various FTL APIs.
- Explore the FTL [client APIs](ftl/api).
